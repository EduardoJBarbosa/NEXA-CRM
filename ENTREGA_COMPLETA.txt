COMO RODAR:

1. Com Docker (RECOMENDADO):
   $ cd "CRM Nexa"
   $ docker-compose up --build

   - Frontend: http://localhost:5173
   - Backend: http://localhost:3001
   - Postgres: localhost:5432

2. Sem Docker:
   # Backend
   $ cd backend
   $ npm install
   $ npm run prisma:migrate
   $ npm run dev

   # Frontend (em outro terminal)
   $ cd frontend
   $ npm install
   $ npm run dev
